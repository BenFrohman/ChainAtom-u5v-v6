# Strange duality for the suspension, not for the curve

**Author:** Benjamin Stanley Frohman  
**Copyright:** © 2026 Benjamin Stanley Frohman  
**License:** Apache-2.0

Arnold's strange duality pairs 14 exceptional unimodal surface singularities. \(W\) is not on that list: the curve has inner modality \(6\), and the suspension \(W+z^2\) has Milnor number \(25\).

Ebeling–Takahashi apply to every invertible polynomial in three variables. Suspending gives a Type II pair:

\[
\begin{aligned}
W+z^2&: \text{Dolgachev }(2,5,10),\ \text{Gabrielov }(2,6,8),\\
W^T+z^2&: \text{Dolgachev }(2,6,8),\ \text{Gabrielov }(2,5,10).
\end{aligned}
\]

The triples swap. Arithmetic and the citation are in [SingularityLab/docs/STRANGE_DUALITY.md](https://github.com/BenFrohman/SingularityLab/blob/main/docs/STRANGE_DUALITY.md).

This is not a class in \(H^4(V(F))\).
